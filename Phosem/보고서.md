## 5. 한계

### 5-1. 미검출 0은 보장되지 않는다

검증셋에서 불량을 하나도 놓치지 않는 경계를 선택했을 때, 시험셋에서는 **미검출 3건**이 발생했고 정확도는 0.838로 하락했다 (과검 49건)

⇒ 현 데이터 규모에서 미검출 0을 보장하면서 유의미한 자동화는 불가능

### 5-2. 정확도 0.89와 0.90은 통계적으로 구분되지 않는다

전수 판정 정확도 0.886의 95% 신뢰구간은 **[0.862, 0.910]** 으로 목표치 0.900을 포함한다.

검증셋에서 35개 모델 조합을 비교한 결과 val 0.891~0.906 / test 0.868~0.895 였으며 **두 순위 사이에 상관이 없었다**. val 1위 조합의 test는 0.889, val 10위 조합의 test는 0.895였다.

⇒ 단일 정확도 수치가 아니라 커버리지-정확도 곡선으로 성능을 제시한다

### 5-3. 남은 오답의 대부분은 판정 경계 사례

오답 76건 중 과검 31건의 최고 지표는 C(접합부)가 29건(94%)이었다. 과검 46건을 접합부 확대 이미지로 검토한 결과 **40건(87%)에서 정상 대비 육안 식별 가능한 차이**가 확인되었고, 근거 없이 발화한 경우는 6건(양품 426장 중 1.4%)이다.

딥러닝을 쓰지 않은 최소 방법(HOG + 로지스틱 회귀, 5겹 교차검증)으로도 같은 결과가 나온다

| 비교 | AUC |
| --- | --- |
| C 검출 성공분 vs 양품 | 0.951 |
| C 놓친 것 vs 양품 | **0.730** |
| 과검된 양품 vs 정상 양품 | **0.805** |
- 놓친 불량은 흔적이 없는 것이 아니라 **약한 신호**를 가진다
- 과검된 양품은 정상 양품과 **실제로 구분된다**

⇒ 모델의 인식 한계가 아니라 **양불 판정 기준의 문제**

### 5-4. 학습 안정성

동일 코드·동일 데이터에서 seed만 바꿔 3회 학습한 결과 val 정확도가 **0.838~0.904** 로 분포했다. train die 2,017장에 학습 파라미터 11,178,564개로 데이터 대비 모델 용량이 과대하다.

1 epoch 시점에 이미 AP 0.880이 나왔고 45 epoch까지 학습해 얻은 개선은 0.02에 그쳤다 ⇒ 현 성능의 대부분은 ImageNet 사전학습 특징에서 나온다

## 6. 요청 사항

1. 양품 이미지 추가
    - 학습용 양품이 1,278장으로, 과검을 줄이는 가장 확실한 방법이라고 판단합니다.
2. 픽셀 스케일 (µm/px)
    - 픽셀 1개가 실물 몇 µm인지 정보가 필요합니다. crop 크기와 무관한 광학계 값을 의미합니다. 다이 실물 가로 크기만 알려 주셔도 직접 환산 가능합니다.
3. S 표본
    - S 54장으로 학습 및 검증이 어렵습니다. 이미지 증강을 계획하고 있지만, 순수 추가 데이터 공급이 가능한지 궁금합니다.
4. 판정 경계 사례 확인
    - 판정 보류로 분류한 73건의 목록과 접합부 확대 이미지를 함께 전달드립니다. 이 중 14건이 라벨 오류로 확인되면 전수 판정 정확도가 0.900에 도달합니다.

## 7. 공부할 개념

| 개념 | 이 프로젝트에서의 의미 |
| --- | --- |
| MIL (Multiple Instance Learning) | 결함 위치 라벨이 없으므로 다이를 patch 여러 장의 묶음(bag)으로 보고, 그중 최댓값(또는 상위 k개 평균)으로 다이 전체를 판정 |
| 선택적 예측 (selective prediction) | 확신이 낮은 입력은 판정을 거부하고 사람에게 넘기는 방식. 커버리지와 정확도의 교환 관계로 성능을 제시한다 |
| AP (Average Precision) | threshold 없이 순위 품질만 재는 지표. 불량 비율(기저 AP)로 나눈 배수로 봐야 데이터가 바뀌어도 비교 가능 |
| 정확도의 신뢰구간 | 이항 비율의 표준오차 √(p(1-p)/n). n=668, p=0.886이면 ±0.024 — 0.886과 0.900을 구분할 수 없는 이유 |
| 모델 선택 과적합 | 검증셋으로 threshold·집계 방식·모델 조합을 여러 번 고르면 검증셋에 맞춰지는 현상. val 순위와 test 순위가 무관했던 이유 |
| 라벨 노이즈 | 정답 자체가 흔들리는 상태. 성능의 상한을 제한하며, 모델을 개선해도 넘을 수 없다 |
| 전이학습 / BatchNorm 동결 | ImageNet 사전학습 특징을 가져와 소량 데이터에 적응. 동결 구간의 통계값이 갱신되면 그 특징이 훼손되므로 막는다 |
| TTA · 앙상블 | 추론 시 반전 평균 / seed가 다른 모델의 점수 평균. 우연한 오류를 상쇄하지만 새 정보를 주지는 않는다 |
| 다중 라벨 분류 | 한 다이에 P·S·C가 동시에 있을 수 있어 softmax(택1)가 아니라 지표마다 독립 sigmoid를 쓴다 |
| HOG + AUC | 딥러닝 이전의 고전 특징. 이걸로도 구분되면 "이미지에 흔적이 있다"는 독립 증거가 된다. AUC 0.5는 무작위, 1.0은 완전 분리 |
| 이상 탐지 (anomaly detection) | 양품만으로 정상 분포를 만들고 벗어난 정도를 재는 방식. 시도했으나 해상도 문제로 AP 0.510에 그쳐 채택하지 않았다 |
