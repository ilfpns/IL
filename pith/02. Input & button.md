이번에는 개발에 사용된 Data sheet 사진 먼저 첨부한다.

Nucleo위의 버튼은 PC로 제어한다. 이를 실제로 13pin에 매핑되어 있으므로 CRL이 아닌 CRH로 접근한다.

 Step 1. 
 APB2ENR를 해준다. APB2는 다른 GPIO 주변 장치를 의미하고, APB는 uart, spi, i2c, timer 같은 주변 장치를 의미한다.

```c
#define RCC_APB2ENR_IOPCEN (1UL << 4)
RCC->APB2ENR |= RCC_APB2ENR_IOPCEN; 
```

Step 2.
13번 핀을 설정해야한다. 일반 LED와 똑같이 CNF13, MODE13을 켜준다.
![[Pasted image 20260826202216.png]]
여기서 위 5pin은 led 제어핀이고, 13pin은 버튼이다. 

왜 어째서 5는 MODE5에 0이 붙고, 13은 CNF에 1이 붙을까?

![[Pasted image 20260826212926.png]]

CNF13 : 00
CNF13_0 : 01
CNF13_1 : 10
CNF13_1 | CNF13_0 : 11
을 의미하며 우리는 10을 쓰므로 CNF13_1을 사용한다. 이전 주소 체계는 16진수로 0x3UL을 사용했지만 1, 0은 2진수 이므로 0x2UL을 사용한다.

MODE는 동작 모드와 최대 속도를 나타낸다

![[Pasted image 20260826213415.png]]

- MODEy : MODEx 에 대한 설정

Step 3.
```c
#define GPIO_IDR_IDR13 (1UL << 13)
#define GPIO_ODR_ODR13 (1UL << 13)
```
입력은 새로운 핀인 IDR, ODR을 활성화 해주어야한다.
- ODR : Output data reggister (출력 대응 레지스터) 
- IDR : Input data register (입력 대응 레지스터)


```c
    GPIOC->CRH &= ~(GPIO_CRH_CNF13 | GPIO_CRH_MODE13);
    GPIOC->CRH |= GPIO_CRH_CNF13_1;
    GPIOC->ODR |= GPIO_ODR_ODR13;
```
GPIOC의 CRH과 ODR에 각 설정을 넣어준다.


```c
        if ((GPIOC->IDR & GPIO_IDR_IDR13) == 0) {
```
input 확인은 기존 IDR과 비교하여 input을 확인한다.
