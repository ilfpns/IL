Mutiple Instance Learning은 원래 이미지에서 patch를 무작위로 진행하여 기존 이미지 라벨링을 그대로 반영하는 것이었다. 여기서 발생하는 문제점은 결함이 국소적이라는 문제이다. 기존 이미지에서 Patch한 이미지가 8장이라고 하면, 1장만 이물질이 포함되고, 남은 7장은 정상 이미지인 셈이다.

⇒ 라벨을 patch 하나하나에 붙이지 않고, patch 묶음 (bag) 전체에 붙이는 방식을 사용한다

- bag : 이미지 한 장에서 뽑은 patch 8장
- bag label : 이미지 라벨
- MIL 가정 : bag이 불량이면 그 안에 불량 patch가 최소 1장은 있다고 판변, bag이 정상이면 그 안에 patch 전부 정상

⇒ 특정 어느 patch가 불량인지는 알 수 없지만, bag이 불량이므로 그 bag안에 적어도 불량이 하나 있다는 가정

최종 구조

기존 무작위 patch + die 라벨 ⇒ 단일 분류는 라벨 노이즈로 인한 학습 붕괴 ⇒ 오류 판별이 특정 클래스로 몰리며 불확실 AC 출력으로 구조 변경 

- MIL : die당 patch 8장 (ROI 2장 + 무작위 6장) → max logit에 die 라벨 BCE
    - Max logit : 모델에서 가장 잘 판별되는 class 점수
    - BCE : 예측과 정답 차이를 수치화하는 함수
- 다중 라벨 : P/S/D/B/C 5개의 클래스를 sigmoid 식으로 분류. 조합 클래스는 지표 동시 양성으로 분해
    - PD같은 희귀 클래스도 학습에 기여함
    
    ```python
    # Sigmoid 식 분류
    P : 1
    S : 10
    C : 11
    D : 9
    B : 4
    ```
    
- ROI : C 접합 결합은 위치 고정으로 집중 확인 부분 생성
    - 학습 샘플링 편향 + 푸론 시 ROI 함
