## 1. 피드백 반영 사항

### 1-1. 학습된 가중치 미제출

가중치·설정·threshold를 함께 저장하는 셀을 추가했습니다.

```
phosem_v3.pt
├── state_dict          학습된 가중치
└── meta
    ├── thr_bin         0.880   양불 판정 threshold (val에서 고정)
    ├── thr_r95         0.462   recall 0.95 운영점
    ├── thr_letter      지표별 threshold (P/S/D/B/C)
    ├── patch, stride, roi_c, k_roi, k_rand, channels, pool
    ├── split_seed      42
    ├── n_train / n_val / n_test
    └── test_ap / test_recall / test_precision / test_acc
```

### 1-2. 정답지 CSV로 직접 채점

⇒ 현재 제대로 된 라벨링 데이터를 사용하고자, CSV 정답지에 대응되는 이미지들의 심층 라벨링을 진행 중입니다.

### 1-3. 집계를 max 대신 상위 몇 개의 평균으로

patch 148장을 한 번만 추론하고 상위 16개 값을 저장해 두는 방식으로 만들었습니다. k를 바꿔도 다시 추론하지 않습니다.

```
k = 1, 2, 4, 8, 16 에 대해 val AP / test AP / test F1 / 양품 오검출률 비교
```

k는 val AP만 보고 고를 계획입니다.

### 1-4. 채점 결과를 CSV로 저장

새로 추가된 채점 셀이 `phosem_2000_scores.csv`를 남깁니다.

```
번호, 원본파일명, 불량점수, P점수, S점수, D점수, B점수, C점수
```

지표별 점수도 함께 남겨서, 나중에 집계 규칙을 바꿔 재계산할 수 있게 구성했습니다.

### 1-5. ROI가 제 값을 하는지 확인

오검출 22건 중 18건의 최고 지표가 C입니다.
ROI patch를 항상 접합부에서 뽑기 때문에 양품의 접합부에도 C head가 반응하는 것으로 예상합니다.

ROI는 `ROI_C = (300, 230, 556, 486)` 으로 하드코딩되어 있고, 이 좌표는 제 crop 정렬을 보고 정한 값입니다.
2,000장 쪽 crop 기준이 다르면 이 사각형이 접합부를 벗어납니다. 자료 6페이지에서 ROI 효과가 보이지 않았던 것이 학습 부족이 아니라 정렬 불일치 때문일 가능성이 있습니다. 이미지를 받으면 사각형을 겹쳐 그려 확인하는 셀을 준비해 두었습니다.

crop 앱도 추가 테스트를 진행할 예정입니다.

### 1-6. 픽셀 스케일 (µm/px)

픽셀 1개가 실물 몇 µm인지를 뜻하며, crop 크기와 무관한 광학계 고정값입니다. 미해결 — 계산식은 구현되어 있어 값 하나만 넣으면 즉시 산출되고, 현재는 후보 시나리오 표만 출력됩니다.

| FOV(µm) | µm/px | 5µm (원본 px) | 5µm (256 resize px) |
| --- | --- | --- | --- |
| 200 | 0.25 | 20.0 | 6.40 |
| 400 | 0.50 | 10.0 | 3.20 |
| 800 | 1.00 | 5.0 | 1.60 |
| 1600 | 2.00 | 2.5 | 0.80 |
| 3200 | 4.00 | 1.2 | 0.40 |
- 원본 800×800을 256으로 줄이면 3.12배 축소됩니다.
- 256 resize에서 5µm가 1~2px 이하면 resize 방식으로는 검출이 불가능합니다. 이는 patch 방식을 선택한 근거입니다.
- patch 방식에서는 5µm 결함의 원본 픽셀을 보존할 수 있기 때문입니다.

## 2. 자체 발견 수정사항

### 2-1. pos_weight 이중 보정

샘플러가 이미 1:1로 맞추는데 `pos_weight`가 전체 분포 기준으로 한 번 더 가중을 걸고 있었습니다.

```
수정 전  pos_weight = ((len(tr_items) - cnt) / cnt).clamp(max=20.0)
수정 후  pos_weight = (n_bad / cnt).clamp(max=5.0)
```

### 2-2. 학습량 보정

⇒ 자료 5페이지의 "걸음수만 늘려도 AUC 0.526 → 0.601"을 근거로 학습량을 늘렸습니다.

| 항목 | 이전 | 이번 |
| --- | --- | --- |
| epochs | 40 | 120 (조기 종료로 46에서 종료) |
| bag / 불량 die | 2배 | 6배 |
| batch_size | 8 | 16 |
| learning rate | 1e-3 | 2e-3 |
| patience | 8 | 25 |
| LR 스케줄 | 없음 | warmup 3 epoch + cosine 감쇠 |
| gradient clipping | 없음 | max norm 5.0 |
| best epoch 선택 | 단일 AP | AP 3회 이동평균 |

loss 0.679 → 0.529, best는 epoch 21에서 선택되었습니다.

!09_curves.svg

train loss는 내려가지만 검증 AP는 여전히 진동합니다. threshold가 0.9 근처에서 안정된 것이 이전과 다릅니다.
