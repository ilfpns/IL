## 3. 변경점

### 3-1. ROI 축소 및 링 샘플링

메사 위치를 이미지마다 자동 검출(Hough)해 기준점 구축. 4,187장 전부에서 중심이 **(522, 277) ±2px** 로 일정해, 고정 ROI 구축 및 확인.

접합부 ROI를 256×256 → **180×180** 으로 좁히고, patch 표본을 세 곳으로 분배.

| 표본 | 장수 | 대상 |
| --- | --- | --- |
| 메사 링 (임의 각도) | 3 | B 끊김 |
| 접합부 박스 | 2 | C 접합부 |
| 무작위 | 7 | P 이물질 |

### 3-2. 학습 설정

ImageNet 사전학습을 ResNet18(11,179,590 파라미터)로 교체하고 lr 3e-4 / batch 8 로 낮췄습니다. 동결 구간의 BatchNorm 갱신을 막고, 밝기·대비 증강을 추가

- 63 epoch 조기 종료

### 3-3. threshold 변동 대응

위 그림 오른쪽에서 보이듯, 매 epoch 선택되는 threshold가 0.04~0.99를 오간다. 원인을 두 가지로 분리해 대응

| 원인 | 대응 | 상태 |
| --- | --- | --- |
| 정확도 곡선이 평평함
(thr 0.5~0.95 구간 차이 0.02 미만) | 동점 구간의 끝값이 아닌 **중앙값** 선택 | 적용 완료 |
| 검증 표본 부족
(양품 60장만 보고 FP를 6.6배 보정) | 검증 양품 200장으로 확대, 보정계수 2.0으로 감소 | 적용 완료 |

배포 시에는 고정된 하나의 threshold를 가중치와 함께 확정해야 한다.

⇒ 학습 중에는 매 epoch 다시 고르지만, 배포되는 값은 최종 모델에서 val로 한 번만 고른 뒤 가중치와 한 쌍으로 저장하면 된다.

⇒ 배포 관점에서는 문제가 되지 않는다. 

⇒ 실제로 val에서 고른 값을 test에 옮겼을 때 정확도는 0.893 → 0.875로 차이가 0.018이다.

## 5. 한계

### 5-1. threshold가 값으로 고정되지 않음

!g3_thr.svg

정확도 곡선이 0.5~0.95 구간에서 평평하다
⇒ 어디를 잘라도 결과가 비슷하므로 매 epoch 다른 값 선택

- 최고 0.872 (thr 0.90) / 최저 0.389 (thr 0.00)
- thr 0.5 – 0.95 구간 정확도 차이 0.02 미만

⇒ 대응 방안은 **3-3 참고**

### 5-2. 점수가 확률이 아님

!g6_bucket.svg

점수 90~100 구간의 실제 불량률이 88%인데, 그 아래는 41% → 23% → 31% 로 순서가 맞지 않는다.

- 순위는 신뢰 가능 / 점수 값 자체는 확률로 해석 불가
- "몇 점 이상이면 자동 확정" 기준을 세울 수 없음

⇒ val 기반 Platt scaling으로 점수를 확률로 변환 예정

### 5-3. B(끊어짐) 광학 판별 불가

B 56장 / C 50장 / 양품 56장을 뽑아, 딥러닝이 아닌 최소 방법(HOG + 로지스틱 회귀, 5겹 교차검증)으로 분리 가능성만 측정

| 보는 범위 | C vs 양품 | B vs 양품 |
| --- | --- | --- |
| 다이 전체 (128px 축소) | 0.901 | **0.426** |
| 메사부 원본 해상도 | 0.875 | **0.579** |
| 메사 링만 펼침 | 0.901 | **0.595** |
- AUC 0.5 = 무작위
- **같은 방법으로 C는 0.90, B는 0.5 근처**
- 범위를 좁힐수록 소폭 상승하나 실용 수준 미달

딥러닝 모델 결과도 같습니다 — 놓친 B의 불량 점수가 0.02~0.04로, 애매해서 틀리는 것이 아니라 아무 신호도 보지 못하고 있습니다.

⇒ B가 전기 측정 기반 라벨이면 광학 이미지에 흔적이 없는 것이 정상

⇒ 이 경우 B는 이미지 AI 대상이 아니며, 대상 범위를 **P·S·D·C로 확정** 필요
