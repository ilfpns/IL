    지금까지의 개발 과정은 다음과 같았다.
    
    ```jsx
    첫 데이터 -> 데이터 학습 -> 과적합 -> 모델 개선 및 추가 데이터 -> 라벨링 -> 학습 후 모델 개선 -> 라벨링한 데이터로 0.93 목표 당성 -> 학습 라벨 데이터가 유효한 데이터가 아님 (정해진 대로 라벨링 해야함)
    ```

왜 교수님은 Resnet50의 Layer 2, 3을 제안했을까?

Resnet 모델은 CNN 모델 중 대표적인 모델이다. 이는 Layer (층)이 깊어질수록 성능이 떨어지는 문제를 정답과 입력값의 차이를 수식에 추가하여, 층을 깊게 만든 모델이다. 
Resnet의 Layer는 각기 다른 역할을 한다. 원래 Backbone도 Layer/block의 모음이고, Layer는 층마다, 스크래치, 선, 점, 면, 곡선 등을 잡으며 구체화 한다.

1. Layer 1 : 색, 단순 패턴
2. Layer 2 : 질감, 국소적 구조
3. Layer 3 : 복잡한 형태, 물체 구조
4. Layer 4 : 고수준 의미 특징

위와 같은 식이다. 그렇기에 Layer 2에서 작은 흠집, 질감, 모서리, 패턴 등을 추출하고, Layer 3에서 형태, 부분적 구조, 복잡한 패턴을 추출한다. 반대로 1, 4 Layer는 너무 고/저 수준이기에 사용하지 않는다.

Anomaly Detection (이상탐지)

⇒ 데이터에서 예상을 벗어나는 특징/패턴을 보이는 데이터를 잡아냄
⇒ 학습 데이터의 특징과 다르게 나타나는 특징을 잡아냄

- 분류 : 두 구분할 수 있는 범주에서 데이터의 포함을 판단하는 것
- 이상 : 다수의 범주를 고려하여, 이상치가 아닌 데이터를 sector로 묶어 구분짓는 것

다수의 범주 (정상 특징 벡터)를 고려하여, 이상치 (새 데이터) 이상의 데이터를 이상탐지함. 다수의 범주는 기준이 필요하기 때문에, 다수의 정상 데이터에서 정상 특징 벡터를 추출해야 한다.

⇒ PatchCore는 Anomaly detection 모델을 구현한 것 중 하나이다. 
PatchCore는 하나의 이미지를 여러 Patch로 나누어, 해당 Patch에서 특징을 추출한다. 그렇게 일반 특징 벡터 (Feature Bank)보다 큰 Memory Bank를 가진다.
하나의 데이터를 여러 Patch로 나누어 여러 특징을 얻기 때문에 Memory Bank는 일단 Feature Bank보다 훨씬 많은 특징을 추출한다. 

PatchCore는 이미지를 여러 Patch로 나눈 것에서 특징을 추출하기 때문에 더욱 미세한 특징까지 추출할 수 있다.  ****PatchCore가 이상탐지를 구현하는 방법 중 하나이고 그중에서도 지역적인(local) 이상을 세밀하게 찾는 방식이다.
