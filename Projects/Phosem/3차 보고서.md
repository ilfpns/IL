## 5. 한계

### 5-1. 미검출 0은 보장되지 않는다

검증셋에서 불량을 하나도 놓치지 않는 경계를 선택했을 때, 시험셋에서는 **미검출 3건**이 발생했고 정확도는 0.838로 하락했다. (과검 49건)

⇒ 현 데이터 규모에서 미검출 0을 보장하면서 유의미한 자동화는 어렵다고 판단

### 5-2. 정확도 0.89와 0.90은 통계적으로 구분되지 않는다

전수 판정 정확도 0.886의 95% 신뢰구간은 **[0.862, 0.910]** 으로 목표치 0.900을 포함한다.

검증셋에서 35개 모델 조합을 비교한 결과 val 0.891~0.906 / test 0.868~0.895 였으며 두 순위 사이에 상관이 없었다. val 1위 조합의 test는 0.889, val 10위 조합의 test는 0.895였다.

⇒ 단일 정확도 수치가 아니라 커버리지-정확도 곡선으로 성능을 제시한다.

### 5-3. 남은 오답의 대부분은 판정 경계 사례

오답 76건 중 과검 31건의 최고 지표는 C(접합부)가 29건(94%)이었다. 과검 46건을 접합부 확대 이미지로 검토한 결과 40건(87%)에서 정상 대비 육안 식별 가능한 차이가 확인되었고, 근거 없이 발화한 경우는 6건(양품 426장 중 1.4%)이다.

딥러닝을 쓰지 않은 최소 방법(HOG + 로지스틱 회귀, 5겹 교차검증)으로도 같은 결과가 나온다

| 비교 | AUC |
| --- | --- |
| C 검출 성공분 vs 양품 | 0.951 |
| C 놓친 것 vs 양품 | **0.730** |
| 과검된 양품 vs 정상 양품 | **0.805** |

⇒ 모델의 인식 한계가 아니라 양불 판정 기준의 문제
