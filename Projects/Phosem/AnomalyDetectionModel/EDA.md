교수님 제안은 데이터의 입력 해상도를 `868 * 868` 로 확대하는 것이다. 입력 해상도를 `868` 로 늘렸을 떄 장점은 다음과 같다. 

- Important
    
    새 제안에 방향이 정답 방향이어야 한다. 이상한 방향으로 뻘짓하면 안 된다.
    
1. 결함이 뭉개지지 않음
    - 애초에 기본 입력 pixel이 크기 때문에, 작은 결함이 보다 더 묻히지 않음
    - MIL 학습에 사용한 입력 해상도와 비슷한 크기를 가짐
2. 실제 수광창 크기에 대응
    - 실제로 die가 빛을 받는 수광창의 크기가 현재의 `320 * 240` 에서는 찌그러진 이미지로 들어온다.
    - `868 * 868` 에 입력 해상도를 맞추면 수광창과 비슷한 비율을 가진다.

X들에 대한 입력으로 Z는 Latent space에 vector 데이터로 모이게 된다. 여기서 전체를 대표하는 일부를 뽑은 것이 Coreset이다.
현재는 214만개의 Feature 중 10만개를 Coreset으로 특정했다.

- Coreset
    
    첫 데이터를 기점으로 최대 거리에 있는 데이터를 포함하고, 그 최대거리 데이터에서 다시 최대거리 데이터를 구하며, 이를 10만번 반복하여 웬만한 특징을 다 담는 (전체를 대표할 수 있는) Set를 만드는 것이다.

    Resnet 2Layer는 데이터를 1/8로 해상도를 낮춘다. 그렇기 때문에 898 * 898은 109 * 109가 된다. 
    이 11,881개의 조각 벡터는 비교 기준이 되는 Bank와의  거리를 구한다.
    
    기준 Bank와 거리가 가장 먼 벡터 데이터 사이의 거리를 점수 최댓값이며, (x, y)는 해당 데이터 위치를 의미한다.
    
    ---
    
    ```jsx
            x →  0   1   2  ...  54  ...  107  108
       y  0      ┌─────────────────────────────┐
       ↓  1      │                             │
          2      │                             │
         ...     │          다이 중앙          │
          54     │                             │
         ...     │                             │
         107     │                             │
         108     └─────────────────────────────┘
    ```
    
    die 데이터는 Layer 2에서 격자로 잘린다. (109 * 109)
    
    상위 데이터 12개의 격자 위 (x, y)데이터를 보았을 때 x나 y값이 109,나 0에 근접한다. 
    
    ⇒ 데이터의 가장자리가 많이 차이난다. ( 가장자리가 격자 배치 상 끝이기 떄문)
    
    가장 Anomaly score가 높은 R4_-1_4를 기준으로 보겠다.
    
    ```jsx
      대표  점수_상위12평균    점수_최댓값  뱅크조각수  최대위치_y  최대위치_x
      R4_-1_4  16.479889       17.192923    192      87      16
    ```
    
    R4_-1_4 데이터를 기준으로 11,881개의 격자 칸이 존재하고, 그 칸 중 Anomaly Score가 가장 높은 격자칸 상위 12개의 평균은 16.479889이고, 가장 차이나는 격자 칸 하나의 값이 17.192923인 것이다. 이 데이터는 우리가 뽑은 Bank Coreset에 192개의 격자만이 유효하다. 이는 좌표평면으로 (87, 16)에 위치한 칸이다.
