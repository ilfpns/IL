PTQ (dynamic)를 개발해 볼 예정이다. 앞서 구축한 Yolov8는 LSTM 모델로 바꾸게 되었다.

dynamic quant는 활성화와 가중치의 자료형을 변경한다. 가중치는 고정되어 메모리에서 가져온다. 그렇기에 이 동적 양자화는 메모리 개선에 초점을 둔 기법이다.

LSTM은 큰 가중치를 한 번 사용한다. 4096 * 4096 size의 FC Layer를 계산할 때 가중치 파일을 불러온다. 이 경우 메모리 대역폭을 조절하여 속도나 무게를 개선할 수 있을 것이다. 
반면 Conv는 3 * 3 * 256 size의 작은 연산을 여러번 진행한다. 이는 가중치를 캐시에 올려서 빠르게 사용하면 되므로 속도 개선을 크게 느끼기 힘들다.

또한 한 layer가 무거운 LSTM을 경량화 하는 것이 더 의미있는 양자화이다.

![[Pasted image 20260916221808.png]]두 모델은 병목 포인트가 다르고, INT8 양자화는 LSTM에 더 적합한 것이다.

다시 말해 내부에사 한 번에 큰 행렬곱 연산이 들어가는 모델인 LSTM이 적합한 것이다.

활성화에서 이전 Layer가 도착하면 scale을 계산하고 양자화를 진행한다.

dynamic quant 시 Yolo 계열은 레이어마다 활성화를 처리하기 위해서 한 Layer를 여러번 연산하는 과정에서 다음과 같은 행동을 한다.
```
측정 -> 양자화 -> 넘김 -> 본인 다시 역양자화
```
를 만복하며, 오버헤드가 누적된다.

```c
[After] INT8 dynamic (after)
SimpleLSTM(

Size reduction     : 74.4 %

```

1.521 -> 0.389%로 무려 약 74%를 절감했다. 
여기서 Output diff도 아무리 커도 약 0.002 정도를 기록하며 PTQ -> dynamic 양자화를 성공했다.

```python 
    return torch.quantization.quantize_dynamic(model, target_layers, dtype=torch.qint8)
```
이 한 줄로 INT8 양자화를 진행했다.

활성화를 양자화하기 위해서 Calibration을 통해 scale/zero-point를 미리 얻었다. 이건 test를 위한 cali 과정이고, 실제 dynamic은 실행 중에 바로 scale/zero-point를 얻을 수 있으니 cali가 필요 없다.
