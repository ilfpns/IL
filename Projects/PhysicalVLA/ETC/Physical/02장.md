## Torque

토크는 모터가 발생시키는 회전력의 양이다. 즉, 회전 힘을 의미한다.

CAD를 하기 전에 모터에 대한 이해를 먼저 하고자 한다.

먼저 설계를 위한 모터를 선정해야 하는데, 여기서 모터가 발휘해야 할 힘을 먼저 계산해야한다.

---

```py
  팔이 수평 (최악)              팔이 60° 위로              팔이 수직 (최소)
  ■━━━━━━━━● 물체              ●                          ●
                              ╱                          ┃
  수평 거리 = L                ■  수평 거리 = L×cos60°        ■  수평 거리 = 0
  τ = 최대                        = 0.5L → τ 절반            τ = 0
```

위와 같은 상황에서 같은 팔이지만, 자세에 따라 필요 토크가 달라지는 것을 볼 수 있다. 여기서는 거리가 최대로 늘어나는 수평 상태가 최악의 상태이다. (네모와 원까지 거리가 가장 멈)

이러한 최악 상태를 가장 베이스로 잡고, 설계를 진행한다.

```py
 [어깨]━━━━[팔꿈치]━━━━[손목]━━[그리퍼]+[물체]
   │          │          │
   │          │          └ 손목 모터: 그리퍼 + 물체만
   │          └──────────── 팔꿈치 모터: 손목 모터 + 그리퍼 + 물체 + 앞쪽 링크
   └─────────────────────── 어깨 모터: 바깥쪽 전부 (다른 모터들 무게까지!)
```

한 Joint는 본인 밖의 모든 Joint의 무게를 감당한다. 즉, 어깨 Joint는 남은 모든 무게를 지탱해야한다. <br />이러한 원리로 모터는 바깥쪽에서 안쪽으로 갈수록 점점 강한 모터를 사용하는 것이 일반적이다. 물론 최소 토크를 계산해도, 이보다 훨씬 더 들 수 있는 토크를 가지는 모터를 준비해야한다.
