지금까지는 이산 모델을 배웠다. 실수를 사용하는 것이 아닌, LLM을 위해 이산적 Tokenization을 진행하는 식이다.

연속 값을 출력하는 가장 쉬운 방법은 회귀(regression)이다. 정답과 행동의 예측 차이를 줄이는 방식으로 수로 아웃풋이 나오는 방식이다. 여기서는 평균의 함정이라는 문제가 있다.

## Multimodality

정답이 여러 개인 상황을 Mutimodal이라 하며, 이 상황에서 매번 조금씩 다른 선택을 한다.

정면에 장애물 뒤 물체를 잡으려면 팔을 오른쪽이나 왼쪽으로 옮기면 될 것이다. 여기서 모델은 왼쪽이나 오른쪽으로 가는 것은 맞지만 중앙으로 가는 건 안된다는 것을 표현하면 된다.

여기서 실수를 Action token화 하여 bin으로 관리하는 방식이, 이산적인 방식인 것이다.<br />SmolVLA는 Action token을 사용하지 않고, Flow Matching를 사용한다.

## Diffusion

학습 시 정상 행동에 노이즈를 조금씩 섞어서 완전한 노이즈로 만든다. 이후 추론에서는 완전한 노이즈에서 노이즈를 제거하며, 정상 행동을 찾는 것을 Diffusion이라 한다.

이는 왼쪽이나 오른쪽에서 치우쳐져 시작하는 것부터 문제를 일으키는 방식을 해결하기 위해 소개했다.

단점은 노이즈를 제거하는 과정이 굉장히 여러 갈래라서 많은 시간이 걸린다는 단점이 존재한다.

## Flow Matching

```py
target_action = [
    0.02, -0.01, 0.03,
    0.12, -0.08, 0.15
]
```

모델이 위와 같은 6차원 행동 Action을 가지고 있다고 가정하자. 이는 모델이 최종적으로 생성해야 할 Action이다.

flow matching 방식에서 AI는 처음 랜던한 노이즈 값에서 목표 값까지 값을 바꾸기 위해서 Vector Field를 사용한다. 이 Field에 로봇은 현재 노이즈를 보고 다음 행동의 방향과 속도를 예측한다. 이때 모델이 예측하는 것은 속도 (Velocity)이다.

즉, 모델이 현재 상태를 보고 다음에 어떤 상태로 움직일지 예측하는 것이다.

이를 통해 SmolVLA는 다음과 같은 방식으로 행동을 시작한다.

1. 무작위 Noise를 생성한다.
2. 현재 Noise 진행도를 모델에 입력한다.
3. 모델이 변화 방향과 속도를 예측한다.
4. 예측한 값을 반영해 상태를 업데이트 한다.
5. 반복해서 최종 Action을 만든다.

IK방식이라면, VLA가 EE를 기반으로 하는 Action 값을 먼저 생성하고, IK가 정보에 맞게 각 Joint 값들을 정하므로, 각 값을 목표 값으로 선정하고, Noise를 목표 Action으로 변화시키는 방향과 속도를 반복적으로 예측한다

이러한 방식은 Action Tokenization과 달리 연속값을 Bin으로 양자화할 필요가 없으므로 양자화에 따른 해상도 제한이 없다.
