이제부터 양자화 공부를 본격적으로 해볼 것이다. 

양자화는 AI 모델을 더 적은 비트로 표현해서 메모리와 연산 비용을 줄이고, 추론을 빠르게 하기 위해서이다.

- 빠른 연산
- 메모리 대역폭 감소
- 모델 자체 크기 감소

---

AI 모델 경량화 방식은 크게 4가지이다.
1. Knowledge Distillation (지식 증류)
	- 큰 teacher 모델을 작은 student 모델로 전환하는 것
	- 비슷한 성능을 내도록 낮은 모델을 학습시킴 

2. Pruning (가지치기)
	- 중요하지 않은 파라미터를 제거하는 것
	- 가중치가 (weight) 낮은 파라미터를 제거함

3. Quantization (양자화)
	- 모델의 숫자를 더 적은 비트로 표현하는 것
	- 변수 자료형 자체를 물리적으로 줄임

---

양자화 방식은 크게 2가지가 있다.

- 가중치 : AI학습이 끝나면 고정되는 파일이다.
	- Conv filter
	- FC layer 
	- array
	- 등을 모델 파일로 미리 저장한다
- 활성화 : Layer를 통과하며 중간에 나오는 중간 출력값이다.
	- ReLU 이후 값, Conv 출력 
	- Input에 따라 달라지는 값이다.
- Calibration : 활성화의 범위 값을 추측한다.
	- 대표 샘플 데이터를 모델에 돌려서 대표 활성화값을 얻는다.
		- scale : 정수 1칸이 실수 몇에 해당하는지 나타내는 값
		- zero-point : 실수 0.0이 정수로는 몇에 대응되는지 나타내는 값
		- scale로 활성화의 값을 대략적으로 알아내고, zero-point로 평행이동하여 활성화 값을 맞춘다.


- Post Training Quantization(PTQ)
모델은 먼저 훈련하고, 양자화를 하는 기법들의 상위 개념이다. 하위 개념은 다음과 같다.

- Dynamic Quantization
	- 가중치는 특정 값으로 고정하고, 활성화는 그대로 유지하는 기법이다.
	- weight의 값을 런타임 시점에서 측정한다.
	- 구현이 쉽고, CPU 추론 가속에 주로 사용된다.
	- Framework마다 변환 크기가 다르므로 조심해야한다.
- Static Quantization
	- 가중치와 활성화 모두 고정 값으로 변환한다. 
	- 활성화 범위를 'Calibration data'로 고정하여, 고정 연산을 수행한다.
	- 정확도가 좀 더 좋지만, 사전 캘리브레이션 단계가 필요하다.
	- QAT에서도 사용된다.

- Quantization Aware Training(QAT)
	- 훈련 과정에서 양자화 오차를 시뮬레이션하여, 모델이 그 영향을 학습하도록 한다.
	- 학습 중 fake-quant 모델을 삽입하여 사용한다.
