Hardfault 기능의 동작을 직접 테스트한다. 

- Unmapped
    
    ```c
    static void fault_bad_write(void) {
        usart2_send_string("Fault test 1: write to unmapped address\n");
        flush_uart();
        *(volatile uint32_t *)BAD_ADDRESS = 0xDEADBEEF;
    }
    ```
    
    매핑되지 않은 주소에 쓰기 명령을 시도한 경우이다. 
    
    ⇒ CPU에 매핑되지 않은 주소로, 접근하여 사용할 수 없다.
    
    ```c
    User input : fault 1
    Fault test 1: write to unmapped address
    PITH boot: build Nov 17 2026 21:57:31
    HardFault: PC=0x08001270 LR=0x0800122F CFSR=0x00000400
      tick=53005 task=2
    ```
    
    이에 `Fault test 1: write to unmapped address`  에러가 발생한다
    
    - PC : 다음 실행 명령어 주소
    - LR : 현재 실행 함수 종로 이후 돌아갈 주소
    - CFSR : 오류가 저장되는 디버깅 레지스터
        - 0x00000400 : IMPRECISERR, 쓰는 과정에서 오류 발생
- Null function
    
    ```c
    static void fault_null_call(void) {
        void (* volatile null_func)(void) = (void (*)(void))0;
    
        usart2_send_string("Fault test 2: call function pointer 0\n");
        flush_uart();
        null_func();
    }
    ```
    
    이는 강제로 null을 가리키는 함수를 호출하는 것이다. 가장 처음에 void 반환 null_func의 시작 주소에 void 0을 넣어 null로 시작하도록 강제한다. 
    
    volatile을 사용한 이유는 컴파일러가 자동으로 null을 사용하지 않는다고 판단하여 최적확할 수 있기 때문이다.
    
    ```c
    User input : fault 2
    Fault test 2: call function pointer 0
    PITH boot: build Nov 17 2026 22:12:37
    HardFault: PC=0x00000000 LR=0x0800125D CFSR=0x00020000
      tick=306805 task=2
    ```
    
    주소가 0인 함수 호출 오류를 출력한다.
    
- Undefined instruction
    
    ```c
    static void fault_undefined(void) {
        usart2_send_string("Fault test 3: undefined instruction\n");
        flush_uart();
        __asm volatile ("udf #0");
    }
    ```
    
    정의되지 않은 명령 호출
    
    ```c
    User input : fault 3
    Fault test 3: undefined instruction
    PITH boot: build Nov 17 2026 22:21:43
    HardFault: PC=0x08001276 LR=0x08001277 CFSR=0x00010000
      tick=28615 task=2
    ```
    
- Zero div
    
    ```c
    static void fault_div_zero(void) {
        volatile int dividend = 1;
        volatile int divisor = 0;
    
        SCB->CCR |= SCB_CCR_DIV_0_TRP_Msk;
        usart2_send_string("Fault test 4: divide by zero\n");
        flush_uart();
        volatile int result = dividend / divisor;
        (void)result;
    }
    ```
    
    `SCB->CCR |= SCB_CCR_DIV_0_TRP_Msk;`  0으로 나눈 것을 넘어간다.
    
    이후 0으로 나누는 것을 강제하여 오류를 발생시킨다. 
    이 역시 volatile을 통해 0으로 나누는 것을 최적화하는 컴파일러를 막는다. 
    
    ```c
    User input : fault 4
    Fault test 4: divide by zero
    PITH boot: build Nov 17 2026 22:23:27
    HardFault: PC=0x080012A8 LR=0x080012A5 CFSR=0x02000000
      tick=30214 task=2
    ```
    
- Not unaligned
    
    ```c
    static void fault_unaligned(void) {
        static uint8_t buf[8];
        volatile uint32_t *odd = (volatile uint32_t *)(buf + 1);
    
        SCB->CCR |= SCB_CCR_UNALIGN_TRP_Msk;
        usart2_send_string("Fault test 5: unaligned word access\n");
        flush_uart();
        volatile uint32_t value = *odd;
        (void)value;
    }
    ```
    
    CPU 워드 단위로 데이터를 읽는다. 그러므로 주소는 4의 배수로 증가한다. 여기서 + 1을 강제로 진행하며, 정렬 오류를 발생시킨다.
    
    워드는 기기마다 다르다. 64bit 운영체제는 64워드로 한번에 8바이트를 읽을 것이고, 32bit는 CPU한번에 4바이트를 읽을 것이다. STM32F103은 STM + 32이므로 한 원드가 4바이트이다.
    
    ```c
    User input : fault 5
    Fault test 5: unaligned word access
    PITH boot: build Nov 17 2026 22:26:36
    HardFault: PC=0x080012E2 LR=0x080012E1 CFSR=0x01000000
      tick=5405 task=2
    ```
    
- ISR kick
    
    ```c
    void EXTI0_IRQHandler(void) {
        __asm volatile ("udf #0");
    }
    
    static void fault_in_isr(void) {
        usart2_send_string("Fault test 6: undefined instruction inside ISR\n");
        flush_uart();
        NVIC_SetPriority(EXTI0_IRQn, 2);
        NVIC_EnableIRQ(EXTI0_IRQn);
        NVIC_SetPendingIRQ(EXTI0_IRQn);
        for (;;) { }
    }
    ```
    
    EXTI를 강제로 사용하여 구현하였다.
    
    ISR에서 `udf #0` 을 사용하며, 이는 정의되지 않은 명령어를 실행하는 ISR fault를 일으킨다.
    
    ```c
    User input : fault 6
    Fault test 7: undefined instruction inside ISR
    PITH boot: build Nov 17 2026 22:37:47
    HardFault: PC=0x080013F4 LR=0xFFFFFFFD CFSR=0x00010000
      tick=25606 task=2
    ```
    
- Just reset
    
    ```c
    static void plain_reset(void) {
        usart2_send_string("Fault test 8: plain reset (no fault report expected)\n");
        flush_uart();
        NVIC_SystemReset();
    }
    ```
    
    fault 없이 NVIC를 초기화하여 발생시킨다. 
    
    ```c
    User input : fault 7
    Fault test 8: plain reset (no fault report expected)
    ```
