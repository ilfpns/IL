클럭은 일정하게 반복되는 HIGH, LOW 신호를 의미한다. 이에 맞춰 주변 기기들은 동기화를 한다. 
System Core 자체에 클럭을 조정할 수 있고, 각 버스들에 클럭을 따로 조정할 수 있다.

클럭은 외부 클럭 생성 하드웨어인 크리스털을 사용하는 HSE와 내부 클럭 장치인 HSI를 지원한다. 이 두 클럭 생성 장치는 서로 다른 장단점이 존재한다.

- HSE
	- 정교하다
	- 빠르다
	- 크리스털 HW가 필요하다
- HSI
	- 덜 정교하다
	- 비교적 느리다
	- 보드에 내장되어 있다

우리 프로젝트는 HSI를 쓰므로 HSE는 명시만 하고 HSI를 사용한다.

---
- CFGR : Clock Configuration Regi
- RCC : reset clock control로 클럭을 초기화한다.
	- PLL : 클럭 배수 값이다.
	- Prescaler : 클럭 분할비 값이다.


- SW : System clock switch
- SWS : System clock switch status 
- HPRE : APB Prescaler
- PPRE1 : APB1 Prescaler
- PPRE2 : APB2 Prescaler
	- DIV1 : / 1
	- DIV2 : / 2
	- DIV4 : / 4
	- ....


|표현|10진수|2진수|
|---|--:|--:|
|`0x0UL`|0|`00`|
|`0x1UL`|1|`01`|
|`0x2UL`|2|`10`|
|`0x3UL`|3|`11`|
|`0x4UL`|4|`100`|
|`0x7UL`|7|`111`|
위에 표는 이번 챕터에서 사용되는 16진수 수의 표현이다.
```0x``` 자체는 16진수를 의미한다. 
만약 사용하고자 하는 기능이 100을 줘야 켜진다면? ```0x4UL << n```이 되는거다.

APB Prescaler는 비트필드를 보면 1 1 1 이렇게 된다 (because 필드가 3개)
1 1 1 = 1 * 4 + 1 * 2 + 1 * 1 = 7 = 0x7UL

0x3UL이 되는 것이다.
즉 비트필드 한 칸이 1을 의미한다. 이를 이진수로 변환하여 계산하면 된다.
