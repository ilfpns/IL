PITH 프로젝트에서 UART TX/RX를 구현하였다. 실제로 이를 flash하고 uart 입력을 확인했을때 TX는 잘 동작하는 상황이다. 하지만 RX가 동작하지 않으며, RX를 디버깅 해야 하는 상황이다. 

- TX : 버튼을 누를 경우 TX로 문구 출력
- RX : 사용자가 입력한 문자열을 그대로 다시 출력 ← 동작 안 함

            - SWD : 우리가 개발한대로 MCU가 제대로 동작하는지 핀을 하나하나 찍으며 확인할 수 없기 때문에 표준을 만들어 관리하게 되었다. 
            ⇒ 하드웨어 디버깅 인터페이스
                
                
                먼저 표준은 두 분류로 나뉜다.
                
                - JTAG
                    - Joint Test Action Group
                    - 펌웨어에 break문을 걸어가며, 변수에 값이 잘 쓰여지는지, 구문이 잘 싱행되는지 테스트한다. 이 자체로 디버깅 역할을 하며, bin파일을 flash하거나 읽어올 수 있다.
                    - 많은 PIN을 사용하는 HW 장치인 것이 단점이다.
                    - IEEE에서 만듦
                - SWD
                    - Serial Wire Debug
                    - 시리얼로 통신하기 때문에, 클럭 (SWCLK)와 데이터 (SWDIO) 2개의 핀만 사용한다. Break Point 지정으로 펌웨어 디버깅을 진행한다.
                    - ARM이 만듦
                
                두 하드웨어 디버깅 인터페이스는 Boundary scan에 있다. JTAG만이 해당 기능을 지원한다.
                PCB에 연결된 IC 상태를 점검할 수 있으며, 그 밖에도 다음과 같은 역할을 수행할 수 있다.
                
                - IC의 입출력 핀 상태 확인
                - PCB 연결 상태 검사
                - 납땜 불량이나 단선 검사
            
            ST-Link는 PC와 하드웨어 디버깅 인터페이스 (SWD, JTAG) 사이에서 동작하는 장치으로, 다음과 같은 역할을 수행한다.
            
            - MCU에 펌웨어 다운로드
            - Breakpoint 및 Step 디버깅 지원
            - MCU 레지스터와 메모리 접근
            - 디버깅 통신 중계
            
            ST-Link는 PC가 작성한 명령을 MCU가 해석 가능하게, 이해 가능한 하드웨어 통신으로 잇는 장치이다.
