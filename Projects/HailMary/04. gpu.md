GPU는 그래픽용으로 만든 범용 병렬 처리 장치이다. 많은 코어가 따로 동작하는 SIMT 구조이다. 각 스레드가 유연하게 동작하며, 범용 장치이기 때문에, AI에 효율이 뛰어나지는 않다.

Single Instruction, Multiple Threads 구조는 하나의 명령을 여러 스레드가 동시에 실행하는 구조를 의미한다.

---

TPU는 구글이 직접 개발한 딥러닝용 ASIC이다. **systolic array**구조로 매우 빠르게 연산하지만, 유연하게 동작하지 않는다. XLA 컴파일러를 거쳐야 동작하는 단점이 있다.

Application Speciffic Intergrated Circuit으로 특정 목적에 맞춰 만들어진 전용 반도체 칩이다. 
Accelerated Linear Algrebra는 Google에서 만든 머신러닝 연산 최적화 컴파일러로 XLA라고 불린다. 이 컴파일러를 거쳐야 Google 자체 제작 병령 처리 장치인 TPU에서 빠르게 돌릴 수 있는 것이다.

NPU는 병렬 처리 장치보다는 신경망 가속기로 볼 수 있다. 대부분의 엣지 보드에서 사용하는 추론 전용 장치로, INT8같은 저정밀 추론 AI에 적합하다. 

---

보통의 학습 환경에서는 GPU가 많이 쓰이고, 규칙적으로 거대한 행렬곱을 가지는 AI 모델은 XLA 컴파일 후 사용하면 좋다. 경량 모델과 연산자 종류가 제한적인 경우에 NPU를 쓰면 좋다.
