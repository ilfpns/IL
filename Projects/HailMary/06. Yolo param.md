```
model = YOLO("yolov8n.pt")

model.train(

    data=yaml_path,

    epochs=100,

    patience=20,

    imgsz=640,

    batch=16,

    device=0,

    workers=2,

    project=f"{root}/runs",

    name="Hail_Mary"

)
```
욜로는 간단하게 학습과 관련 파라미터 설정이 가능하다. 

epochs에 따라 최대 학습 수가 정해지고, 학습 조기 종료 기준을 patience로 잡는다.
imgsz로 입력 해상도를 설정하고, batch로 GPU가 한번에 처리할 이미지 개수를 지정한다. GPU가 부족할 경우 이 수를 줄일 수 있다. 마지막으로 workers를 통해 대기 프로세스 수를 정한다.

device는 
- 0 : GPU 사용
-  "cpu" : CPU 사용

---

Yolo는 yaml파일이 존재한다
- yaml : yolo에게 어떤 데이터를 어디서 가져와서 어떤 클래스로 학습할지 알려주는 데이터셋 설정 파일
이러한 데이터 위치/클래스 설명 파일을 가지게 된다. Hailmary프로젝트의 Yaml 구조는 다음과 같다.


```
내 드라이브/
└── HM_img/
    ├── data.yaml              (2번 셀이 자동 생성, 직접 만들 필요 없음)
    ├── train/
    │   ├── images/            (학습 사진: 까치집 + 전봇대 섞어서)
    │   └── labels/            (사진과 같은 이름의 .txt)
    ├── valid/
    │   ├── images/            (검증 사진)
    │   └── labels/            (검증 라벨 .txt)
    ├── test_imgs/             (라벨 없는 새 사진, 3번 셀에서 추론용)
    └── runs/                  (학습·추론 후 자동 생성)
        ├── Hail_Mary/
        │   └── weights/       (best.pt, last.pt)
        └── test_pred/         (test_imgs 추론 결과 이미지)
```
