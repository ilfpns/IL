'Attention' Background
Seq2Seq 시퀀스를 인풋으로 받고 시퀀스를 아웃풋으로 내놓는 모델을 위해 제작된 RNN 모델이다.

- Seq : 순서가 있는 데이터 (1 -> 2 -> 3)
- RNN : 시퀀스 구조 데이터를 처리하는 신경망 
	- 신경망 : 입력 데이터를 가중치에 맞게 계산하고, 원하는 출력값을 받는 구조

RNN, LSTM,GRU 모델들 역시 이전 값을 기억할 수 있었다. RNN은 짧은 참조 윈도우를 가지기에, 긴 인풋 시 이를 처리하지 못했다. 

- 병령화 : 시퀀스같은 순서 데이터를 처리하므로 병렬 처리가 불가하다.
- Long Distance Dependency : 참조 윈도우 크기가 고정되어 멀리 떨어진 값들은 관계성이 떨어졌다
LSTM과 GRU역시 RNN보다는 크지만, 유한한 참조 윈도우 크기를 가졌다. 

---

이를 해결하기 위해서 attention 매커니즘 등장하였다. 어텐션 매커니즘은 컴퓨터 소스가 충분하다면 제한 없이 참조 윈도우 크기를 늘릴 수 있었다. 긴 시퀀스가 담는 문맥 역시 이해할 수 있었다. 
또한 병렬화가 가능하며 각 Query와 모든 key를 비교하므로 거리가 먼 정보도 관계를 잃지 않았다. 이렇게 학습 속도가 빨라지고, 큰 데이터셋 역시 적용할 수 있었다. 

=> 입력 길이와 상관 없이 Ateend to (집중할 수 있는)할 수 있었다.

---

 Attention model은 attention 매커니즘을 사용하여 Seq data를 병령처리하고, 거리에 따른 정보를 잃지 않는 모델이다.

--- 

트랜스포머에서 Query, Key, Value는 뭘 의미할까? 
Query는 검색어, Key는 검색된 내용이며, Value는 Key의 내용이다. 

Query에 가장 만족되는 Key를 찾으려면 각 Q, K의 연관성을 알아야한다. 이 사이에는 코사인 유사도 알고리즘을 사용한다. 

- +1 : 가장 유사
- -1 : 가장 비유사

Seq는 순서가 있는 데이터이다. RNN은 이 정보를 가지고 계산하지만, Transformer는 이를 고려하지 않는다. 트랜스포머는 Input Embedding을 하고, 이 사이에 Poitional Encoding을 추가한다. 
입력 임베딩과 같은 차원으로 위치 정보를 담도록 하여 Seq를 보존한다. 

임베딩은은 고차원 공간 데이터를 저차원 공간 데이터로 변환하는 것으로 저차원 공간 데이터에 위치 정보가 추가되는 것이다.
